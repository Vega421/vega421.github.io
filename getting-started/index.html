    Getting Started#

    These are resources for FiveM (GTA V roleplay servers). They support Qbox, ESX and QBCore; the badges at the top of every script page show which frameworks it works with, and Browse by framework groups them.

    Requirements#

    • A FiveM server. OneSync is recommended; it's on by default on current servers.
    • The framework the script is built for.
    • The other resources listed on the script's page. ox_lib is recommended for the nicest notifications, and Qbox already includes it.

    Installing a script#

    1. Open the script's page in Scripts and follow the latest release link.
    2. Download the .zip file under Assets.
    3. Unzip it into your server's resources folder.
    4. Add the script's items to your inventory (see below).
    5. Add ensure <resource name> to server.cfg, below your framework (see below).
    6. Restart the server.

    Adding items#

    Where items go depends on your framework and inventory. Each script page shows the exact code for its items.

    Inventory Where items go
    Default ESX Run the script's .sql file on your database
    ox_inventory ox_inventory/data/items.lua
    Inventory Where items go
    qb-inventory / ps-inventory qb-core/shared/items.lua
    ox_inventory ox_inventory/data/items.lua

    Item images go in your inventory's image folder, for example qb-inventory/html/images/.

    Inventory Where items go
    ox_inventory ox_inventory/data/items.lua

    Qbox uses ox_inventory. Item images go in ox_inventory/web/images/.

    server.cfg order#

    Resources start from top to bottom, so your framework and its libraries must come before any script that uses them.

    ensure oxmysql
ensure es_extended
ensure ox_lib          # optional
ensure <script name>

    ensure oxmysql
ensure qb-core
ensure [qb]            # qb-inventory and other qb resources
ensure ox_lib          # optional
ensure <script name>

    ensure oxmysql
ensure ox_lib
ensure qbx_core
ensure ox_inventory
ensure <script name>

    If you installed with the Qbox txAdmin recipe, keep its order and add your scripts at the end.

    Giving items for testing#

    Framework Command
    ESX /giveitem [player id] [item] [amount]
    QBCore /giveitem [player id] [item] [amount]
    Qbox (ox_inventory) /giveitem [player id] [item] [amount]

    Police jobs on QBCore and Qbox

    Scripts that count police usually only count officers who are on duty. If a script says there aren't enough police, make sure the officers have clocked in.

    Updating a script#

    1. Check the Changelog on the script's page for anything new you need to set up.
    2. Back up your old config files (for example config/config.lua and config/config_server.lua).
    3. Delete the old script folder and put the new release in its place. Don't copy the new files over the old ones, because files can move between versions.
    4. Copy your changed values back into the new config file. Don't copy the old file over it, because new versions can add settings.
    5. Restart the script with ensure <resource name> in the server console, or restart the server.

    Finding errors#

    If something doesn't work, look at the server console and the F8 console in game. Errors show the resource name, for example [tobs_bankrobbery]. Each script page has a Troubleshooting section for the common ones.

    Getting help#

    Open an issue on the script's GitHub repository. Include your framework, the script version and any error from the consoles.
