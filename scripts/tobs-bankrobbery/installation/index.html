    Installation#

    Pick your framework once and every tab on this site follows.

    Requirements#

    Resource Needed? Why
    qbx_core Required Framework
    ox_inventory Required Items (comes with Qbox)
    ox_lib Recommended Notifications, progress bars and the hacking minigame (comes with Qbox)
    ox_target Optional Look-and-click instead of "press E"

    Turn on OneSync

    OneSync is on by default on current servers. The anti-cheat, the GPS tracker and the server-spawned trolleys use it to know where players are.

    Install#

    1. Download tobs_bankrobbery-vX.Y.Z.zip from the latest release.

    2. Unzip it into your server's resources folder, so you get resources/tobs_bankrobbery/.

    3. Add the items. The install/ folder has them ready for every inventory. Players need the Malicious Access Card (id_card_f) to start a heist, and a drill for the deposit boxes (or set TOB.DrillItem = "").

      Copy the items from install/ox_inventory.lua into ox_inventory/data/items.lua:

      ['id_card_f'] = {
    label = 'Malicious Access Card',
    weight = 10,
    stack = true,
    close = true,
    description = 'A cloned access card used to breach bank security systems.',
},

      Item images go in ox_inventory/web/images/.

      Default inventory: run install/esx.sql on your database.

      ox_inventory: copy the items from install/ox_inventory.lua into ox_inventory/data/items.lua.

      qb-inventory: copy the items from install/qb-core.lua into qb-core/shared/items.lua:

      id_card_f = { name = 'id_card_f', label = 'Malicious Access Card', weight = 10, type = 'item', image = 'id_card_f.png', unique = false, useable = false, shouldClose = true, description = 'A cloned access card used to breach bank security systems.' },

      Put an image for each item in your inventory's image folder, for example qb-inventory/html/images/.

      ox_inventory: copy the items from install/ox_inventory.lua into ox_inventory/data/items.lua instead.

    4. Set your police job in config/config.lua:

      TOB.PoliceJob is your police job's name (default "police"). Several jobs: {"police", "sheriff"}. Only officers who are on duty count (TOB.PoliceOnDuty).

    5. Add it to server.cfg, below its dependencies:

      ensure ox_lib
ensure qbx_core
ensure ox_inventory
ensure ox_target     # optional
ensure tobs_bankrobbery

add_ace group.admin command.tobreset allow
add_ace group.admin command.tobpause allow
add_ace group.admin command.tobtest allow
add_ace group.admin command.tobcheck allow

      ensure es_extended
ensure ox_lib        # recommended
ensure ox_target     # optional
ensure tobs_bankrobbery

add_ace group.admin command.tobreset allow
add_ace group.admin command.tobpause allow
add_ace group.admin command.tobtest allow
add_ace group.admin command.tobcheck allow

      ensure qb-core
ensure [qb]          # qb-inventory and other qb resources
ensure ox_lib        # recommended
ensure ox_target     # optional
ensure tobs_bankrobbery

add_ace group.admin command.tobreset allow
add_ace group.admin command.tobpause allow
add_ace group.admin command.tobtest allow
add_ace group.admin command.tobcheck allow

      The add_ace lines let admins use the reset command and (coming soon) the heist switch, test mode and health check. If you use tobs_minigames, put ensure tobs_minigames above ensure tobs_bankrobbery.

    6. Running another Fleeca heist script? Set TOB.FleecaBanks = false in config/config.lua so the two don't clash.

    7. Restart the server. The console shows [tobs_bankrobbery] Version ... is up to date.

    The framework is found automatically

    If the console says No framework found, move ensure tobs_bankrobbery below your framework, or set TOB.Framework to "qbox", "esx" or "qb".

    Giving players the access card#

    The script doesn't hand out cards. The card is used up each heist, so price it with that in mind.

    • Admin command: /giveitem [player id] id_card_f 1
    • Shop: add id_card_f to an ox_inventory shop (ox_inventory/data/shops.lua)
    • Other scripts: crafting, drops or missions

    • Shop: add id_card_f to a black-market shop (for example esx_shops or ox_inventory shops)

    Files#

    tobs_bankrobbery/
├── fxmanifest.lua
├── config/
│   ├── config.lua          # gameplay settings
│   ├── banks.lua           # the banks: positions, cash and cooldown per bank
│   └── config_server.lua   # server-only: Discord webhook, admin command, dispatch
├── locales/locales.lua     # all in-game text
├── bridge/                 # one folder per framework (qbox, esx, qb) + shared/
├── client/                 # the heist, shared by every framework
├── server/                 # the heist and anti-cheat, shared by every framework
├── install/                # items for every inventory
└── stream/                 # bank interior map file

    Updating#

    Delete the old folder, unzip the new release, then copy your changed settings into the new config/ files. Check the changelog for anything new to set up.

    Coming from tobs_blaine

    tobs_bankrobbery is the new name of tobs_blaine. Delete the tobs_blaine folder, change ensure tobs_blaine to ensure tobs_bankrobbery in server.cfg, and copy your settings into the new config/config.lua. The items and the /tobreset command are the same.
