    tobs_bankrobbery#

    v2.0.0 Qbox · ESX · QBCore 6 languages GPL-3.0

    Rob the Paleto Bay bank and all six Fleeca banks. Hack the security panel, open the vault and empty the trolleys before the police arrive.

    Download Installation Source

    At a glance#
    Frameworks Qbox, ESX and QBCore, detected automatically
    Banks Paleto Bay (B1) and six Fleeca banks (F1–F6)
    Uses when running ox_lib, ox_target, ox_inventory, qb-inventory, ps-dispatch
    Languages English, Danish, German, Swedish, Norwegian, Dutch
    License GPL-3.0, free and open source

    Formerly tobs_blaine, and the numbers start at 1.0.0 again

    tobs_bankrobbery replaces the separate tobs_blaine downloads. The version you can download is 2.0.0. The next one is 1.0.0, which comes after it: the script was rewritten enough that the numbering was restarted. See the changelog.

    vRP servers

    vRP is supported up to 2.0.0, the last version with it. From 1.0.0 the script is Qbox, ESX and QBCore only.

    Features#

    • Secure by design

      The server runs every step of the heist and every payout, so mod menus can't skip the hack or fake loot.

      How it works

    • Fun to play

      Laptop hack, thermite, the real bank alarm, deposit boxes to drill, and gold and diamond trolleys.

      Loot and rewards

    • A real chase

      Police alerts and dispatch, plus an optional GPS tracker or dye pack hidden in the loot.

      Police and the chase

    • Built for admins

      Discord logs, an admin reset, restart protection, saved cooldowns and exports for your scripts.

      Server tools

    Banks#

    Bank Config name Per trolley
    Paleto Bay (Blaine County Savings) B1 $50,000–80,000
    Fleeca: Alta, Legion Square, Rockford Hills, Great Ocean Highway, Burton, Harmony F1–F6 $30,000–50,000

    Fleeca banks add an inner gate to hack for the last trolley. Running another Fleeca heist script? Turn them off with TOB.FleecaBanks = false.
