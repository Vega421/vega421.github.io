    Configuration#

    Everything is in config.lua, one of the files you can edit. Every setting is also explained in the file. Restart the script after a change.

    General#

    Setting Default What it does
    Config.Framework 'auto' 'auto', 'qbox' or 'none'. With 'none', job channels are off; everything else works
    Config.StaffAce 'tobs_chat.staff' The ace that makes a player staff (moderation commands and the staff channel)
    Config.MaxLength 256 Longest message a player can send, in characters
    Config.Cooldown 750 Minimum ms between two chat messages from the same player. Commands aren't limited by it
    Config.AllowColorCodes true Lets players colour their messages with ^1–^9. false strips them (script messages keep their colours)
    Config.PlainChat 'global' Where a line without a command goes: 'global', 'ooc' or 'off' (Channels)
    Config.MaxMessages 100 Messages kept in the chat window
    Config.HistorySize 30 Sent messages a player can bring back with ↑
    Config.JoinMessages / QuitMessages true "X joined" and "X left" lines. Skipped while qbx_chat_theme runs, because it sends its own

    Keys#

    Setting Default What it does
    Config.OpenKey 'T' Opens the chat
    Config.MenuKey '' Opens the settings menu. '' = no key by default: players bind it themselves. The gear and /chatsettings always work
    Config.ToggleKey 'L' Cycles when the chat shows. false = no key (/toggleChat still works)

    Players can rebind the keys in the GTA key settings. Changing these only affects players who never pressed them before: that's how FiveM key mappings work.

    Chat history for joiners#

    Config.ChatHistory

    Setting Default What it does
    enabled true Show recent public chat to players who join or reconnect
    size 40 Messages kept
    maxAgeMinutes 30 Older ones aren't shown

    Only normal chat to everyone is kept: never channels, radios, or anything a script sends.

    Channels#

    Config.Channels: every option, with an example, is on the Channels page.

    Speech bubbles#

    Config.Bubbles

    Setting Default What it does
    duration 7000 ms on screen
    height 0.45 Metres above the head

    Emojis and mentions#

    Setting Default What it does
    Config.Emojis true :smile:-style codes and the emoji picker
    Config.Mentions.enabled true @name or @id highlights the message for that player, with a sound
    Config.Mentions.max 5 Most players one message can ping

    Word and spam filters#

    Config.WordFilter

    Setting Default What it does
    enabled true Turns the filter on
    action 'censor' 'censor' replaces the word with ****, 'block' drops the whole message
    words { 'badword', 'anotherbadword' } Whole words, not case sensitive: add your own

    Config.Spam (staff are exempt)

    Setting Default What it does
    enabled true Turns the spam filter on
    repeatSeconds 30 The same message again within this time is refused
    repeatIgnore { 'me', 'do' } Channels never checked for repeats
    caps { enabled = true, minLetters = 12, ratio = 0.7, action = 'lower' } Messages with at least 12 letters, 70 % of them capitals, are lowercased ('lower') or refused ('block')

    Logs#

    Config.Logs. The Discord webhook isn't in this file, because it's a secret: set it in server.cfg (Moderation).

    Setting Default What it does
    console true Print every player message in the server console
    discord true Send to the webhook (does nothing until it's set)
    batchSeconds 5 Collect messages and post them together, so Discord doesn't rate-limit
    chat / channels / moderation true Which kinds of messages are logged

    Themes and defaults#

    Setting Default What it does
    Config.Themes all five The themes players can choose from, in this order: 'frosted', 'midnight', 'compact', 'daylight', 'tinted'. With one left, the theme choice disappears

    Config.Defaults: what new players start with. Every player can change these in their settings menu.

    Setting Default Choices
    theme 'frosted' One of Config.Themes
    accent 'default' 'default' (ice blue), or '#e6b85c' (gold), '#4fd1a5' (mint), '#a29bfe' (violet), '#ff7a93' (rose), '#e9eaee' (white)
    size 100 Text size in %: 90, 100, 115 or 130
    background 'medium' 'light', 'medium' or 'dark'
    width 'normal' 'narrow', 'normal' or 'wide'
    position 'top' 'top', 'middle' or 'bottom' (just above the minimap)
    timestamps false The time on every message
    visibility 'auto' 'auto' (shows on new messages), 'always' or 'hidden' (only while typing)
    fadeSeconds 10 For 'auto': seconds a new message stays: 5, 10, 20 or 30
    bubbles true Speech bubbles above other players' heads
    mentionSound true A sound when someone @mentions you
